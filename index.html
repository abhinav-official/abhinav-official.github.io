Content Engine

Content Engine is a personal automation tool built and operated by Abhinav Jha. It prepares and publishes videos to the owner's own YouTube channels, Interval and Mavi Psychology, from the owner's own computer.

The tool signs in with the owner's Google account through Google OAuth and uses the YouTube Data API only to upload and manage the owner's own videos, thumbnails, captions and playlists.

See the privacy policy for how data is handled.
